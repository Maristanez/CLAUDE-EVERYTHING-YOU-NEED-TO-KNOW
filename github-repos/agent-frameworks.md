# Agent Frameworks

Full-featured platforms for building and running autonomous AI agents.

---

## OpenClaw

**Repo:** [openclaw/openclaw](https://github.com/openclaw/openclaw) | **Stars:** 210k+

The viral AI agent. Persistent, multi-channel, and writes its own skills. The most-starred AI agent project.

**Key features:**
- Persistent memory across sessions
- Multi-channel operation (terminal, web, API)
- Self-improving — writes and installs its own skills
- Plugin ecosystem

---

## AutoGPT

**Repo:** [Significant-Gravitas/AutoGPT](https://github.com/Significant-Gravitas/AutoGPT)

Full agent platform for long-running, autonomous tasks. One of the original "autonomous agent" projects.

**Key features:**
- Long-running task execution
- Web browsing and research
- File creation and management
- Plugin architecture

---

## LangGraph

**Repo:** [langchain-ai/langgraph](https://github.com/langchain-ai/langgraph) | **Stars:** 26.8k

Agents as graphs. Multi-agent orchestration built on LangChain.

**Key features:**
- Graph-based agent architecture
- Multi-agent orchestration
- Streaming support
- State management and persistence
- Human-in-the-loop workflows

---

## OWL

**Repo:** [camel-ai/owl](https://github.com/camel-ai/owl)

Multi-agent cooperation framework. Tops the GAIA benchmark for general AI assistants.

**Key features:**
- Multi-agent cooperation patterns
- Benchmark-leading performance
- Structured agent communication

---

## Dify

**Repo:** [langgenius/dify](https://github.com/langgenius/dify)

Open-source LLM app builder. Workflows, RAG, and agents all-in-one platform.

**Key features:**
- Visual workflow builder
- Built-in RAG pipeline
- Agent orchestration
- API-first design
- Self-hostable

---

## CrewAI

**Repo:** [crewAIInc/crewAI](https://github.com/crewAIInc/crewAI)

Multi-agent with roles, goals, and backstories. Assign personalities and specialties to each agent.

**Key features:**
- Role-based agent design
- Goal-driven execution
- Agent backstories for specialization
- Tool sharing between agents

## CopilotKit

**Repo:** [CopilotKit/CopilotKit](https://github.com/CopilotKit/CopilotKit)

Embed AI copilots directly into React applications.

**Key features:**
- React component library
- In-app AI copilot
