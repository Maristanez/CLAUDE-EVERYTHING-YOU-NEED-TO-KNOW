# Local AI

Run LLMs locally — on your machine, with full privacy, zero API costs.

---

## Ollama

**Repo:** [ollama/ollama](https://github.com/ollama/ollama)

Run LLMs locally with one command. The simplest way to get started with local AI.

```bash
ollama run llama3
```

---

## Open WebUI

**Repo:** [open-webui/open-webui](https://github.com/open-webui/open-webui)

Self-hosted ChatGPT-like interface. Beautiful web UI for local and remote LLMs.

---

## LlamaFile

**Repo:** [Mozilla-Ocho/llamafile](https://github.com/Mozilla-Ocho/llamafile)

LLM as a single executable. Zero dependencies — download one file, run it, get a working LLM with web UI.

---

## Unsloth

**Repo:** [unslothai/unsloth](https://github.com/unslothai/unsloth)

Fine-tune models 2x faster with 70% less memory. Essential for custom model training on consumer hardware.
