# Memory & Context Systems

Tools for giving AI agents persistent memory across sessions.

---

## Mem9

**Repo:** [mem9-ai/mem9](https://github.com/mem9-ai/mem9)

Memory system designed specifically for AI agents. Stores and retrieves contextual information across sessions.

**Use cases:**
- Remember user preferences across conversations
- Store project-specific knowledge
- Build persistent agent state

---

## Codefire

**Repo:** [websitebutlers/codefire-app](https://github.com/websitebutlers/codefire-app)

Persistent memory for coding agents. Remembers codebase context, decisions made, and patterns established.

**Use cases:**
- Maintain coding context across sessions
- Remember architectural decisions
- Track refactoring history

---

## Memobase

**Repo:** [memodb-io/memobase](https://github.com/memodb-io/memobase)

User profile memory for LLMs. Builds and maintains user profiles that persist across interactions.

**Use cases:**
- Personalized responses based on user history
- Remember user preferences and working style
- Build up understanding over time

---

## Codebase Memory MCP

**Repo:** [DeusData/codebase-memory-mcp](https://github.com/DeusData/codebase-memory-mcp)

Transforms your codebase into a persistent knowledge graph accessible via MCP.

**Use cases:**
- Navigate large codebases efficiently
- Understand code relationships
- Persistent codebase understanding across sessions
