# Search & Data Tools

Tools for research, data extraction, and LLM-powered data pipelines.

---

## GPT Researcher

**Repo:** [assafelovic/gpt-researcher](https://github.com/assafelovic/gpt-researcher)

Autonomous research agent that compiles information into structured reports. Give it a topic and get back a comprehensive analysis.

---

## Firecrawl

**Repo:** [mendableai/firecrawl](https://github.com/mendableai/firecrawl)

Turn any website into LLM-ready data. Handles JavaScript rendering, pagination, and complex site structures.

---

## Vanna AI

**Repo:** [vanna-ai/vanna](https://github.com/vanna-ai/vanna)

Natural language to SQL. Ask questions in English, get database queries and results.

---

## DSPy

**Repo:** [stanfordnlp/dspy](https://github.com/stanfordnlp/dspy)

Program (don't prompt) foundation models. A framework for algorithmically optimizing LM prompts and weights.

---

## Spec Kit (GitHub)

**Repo:** [github/spec-kit](https://github.com/github/spec-kit) | **Stars:** 50k+

Spec-driven development. Write specifications, and AI generates the implementation. Built by GitHub.

---

## NVIDIA NemoClaw

**Repo:** [NVIDIA/NemoClaw](https://github.com/NVIDIA/NemoClaw)

Secure sandbox for autonomous agents. Run untrusted agent code in isolated NVIDIA-backed environments.
