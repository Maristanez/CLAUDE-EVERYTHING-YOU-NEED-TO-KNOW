# Agent Orchestration & Multi-Agent

Tools for running multiple Claude or AI agents in parallel, coordinating them, and building virtual teams.

---

## gstack

**Repo:** [garrytan/gstack](https://github.com/garrytan/gstack)

Turn Claude Code into a virtual engineering team. Multiple agents with defined roles working on the same codebase.

---

## cmux

**Repo:** [craigsc/cmux](https://github.com/craigsc/cmux)

Run multiple Claude agents in parallel. Multiplexer for Claude Code sessions.

---

## figaro

**Repo:** [byt3bl33d3r/figaro](https://github.com/byt3bl33d3r/figaro)

Orchestrate Claude agent fleets on your desktop. Manage and coordinate multiple agents from one interface.

---

## claude-squad

**Repo:** [smtg-ai/claude-squad](https://github.com/smtg-ai/claude-squad)

Terminal agents running in parallel sessions. Spin up multiple Claude instances working on different tasks simultaneously.

---

## deer-flow (ByteDance)

**Repo:** [bytedance/deer-flow](https://github.com/bytedance/deer-flow)

Sub-agents and sandboxes through skills. Built by ByteDance for complex multi-step workflows.

---

## SWE-AF

**Repo:** [Agent-Field/SWE-AF](https://github.com/Agent-Field/SWE-AF)

One API call spins up an entire engineering team. Automated software engineering agent field.

---

## AIlice

**Repo:** [myshell-ai/AIlice](https://github.com/myshell-ai/AIlice)

Decomposes complex tasks into dynamic agents. Each sub-task gets its own specialized agent.

---

## Agent Alchemy

**Repo:** [sequenzia/agent-alchemy](https://github.com/sequenzia/agent-alchemy)

Claude Code + plugins + task manager. An integrated environment for building with multiple agents.
