# Agent Infrastructure & Security

Tools for running agents safely — sandboxing, governance, security review, and encrypted communication.

---

## Ghost OS

**Repo:** [ghostwright/ghost-os](https://github.com/ghostwright/ghost-os)

AI agents that operate every Mac app. Full desktop automation through AI.

---

## e2b/desktop

**Repo:** [e2b-dev/desktop](https://github.com/e2b-dev/desktop)

Isolated virtual desktops for agents. Each agent gets its own sandboxed desktop environment.

---

## container-use (Dagger)

**Repo:** [dagger/container-use](https://github.com/dagger/container-use)

Containerized environments for coding agents. Run untrusted agent code safely in Docker containers.

---

## Canopy

**Repo:** [kwalus/Canopy](https://github.com/kwalus/Canopy)

Encrypted P2P mesh for AI agents. Secure communication between distributed agents.

---

## agent-governance-toolkit (Microsoft)

**Repo:** [microsoft/agent-governance-toolkit](https://github.com/microsoft/agent-governance-toolkit)

Security middleware for agents. Policy enforcement, audit logging, and access control for AI agent systems.

---

## claude-code-security-review (Anthropic)

**Repo:** [anthropics/claude-code-security-review](https://github.com/anthropics/claude-code-security-review)

Automated security analysis for pull requests. Claude reviews PRs for security vulnerabilities.

---

## promptfoo

**Repo:** [promptfoo/promptfoo](https://github.com/promptfoo/promptfoo)

Automated security testing for AI models. Red-teaming, prompt injection testing, and vulnerability scanning for LLM applications.
