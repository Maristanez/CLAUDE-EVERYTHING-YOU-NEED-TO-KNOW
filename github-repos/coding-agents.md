# Coding Agents & Dev Tools

Specialized AI agents and tools for software development workflows.

---

## Qwen Code

**Repo:** [QwenLM/qwen-code](https://github.com/QwenLM/qwen-code)

Terminal AI coding agent by QwenLM. Open-source alternative to Claude Code.

---

## gptme

**Repo:** [gptme/gptme](https://github.com/gptme/gptme)

Personal AI agent in the terminal. Lightweight, extensible, and privacy-focused.

---

## Claude Inspector

**Repo:** [kangraemin/claude-inspector](https://github.com/kangraemin/claude-inspector)

See hidden Claude Code prompt mechanics. Understand what's happening behind the scenes in Claude Code sessions.

---

## TDD Guard

**Repo:** [nizos/tdd-guard](https://github.com/nizos/tdd-guard)

Enforces test-first development for AI agents. Ensures Claude writes tests before implementation.

---

## rendergit (Karpathy)

**Repo:** [karpathy/rendergit](https://github.com/karpathy/rendergit)

Convert a Git repo into a single file readable by humans and LLMs. Great for providing full codebase context.

---

## autoresearch (Karpathy)

**Repo:** [karpathy/autoresearch](https://github.com/karpathy/autoresearch)

Autonomous LLM training system. Automates the research-to-training pipeline.

---

## pydantic-ai

**Repo:** [pydantic/pydantic-ai](https://github.com/pydantic/pydantic-ai)

Type-safe agent framework built on Pydantic. Structured outputs, validation, and type checking for AI agents.

---

## claude-deep-research-skill

**Repo:** [199-biotechnologies/claude-deep-research-skill](https://github.com/199-biotechnologies/claude-deep-research-skill)

8-phase research with auto-continuation. Comprehensive research workflows that Claude follows systematically.
