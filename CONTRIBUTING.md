# Contributing

Contributions welcome! This is a community-curated collection.

## Adding a New Tool

1. Determine the category (skill, MCP server, or GitHub repo)
2. Add an entry to the appropriate table in `README.md`
3. Add a detailed entry in the corresponding category file under `skills/`, `mcp-servers/`, or `github-repos/`
4. Include: name, repo link, description, and use cases

## Formatting

- Tables use the format: `| # | Name | Description | Link |`
- GitHub links: `[owner/repo](https://github.com/owner/repo)`
- Each detailed entry should have: repo link, description, and practical use cases

## Categories

| Directory | Content |
|-----------|---------|
| `skills/` | Claude Code skills (SKILL.md files) |
| `mcp-servers/` | MCP server configurations |
| `github-repos/` | Agent frameworks, dev tools, infrastructure |
| `guides/` | Setup tutorials and workflow guides |

## Quality Standards

- Only include tools that are actively maintained
- Prefer tools with significant community adoption
- Include practical use cases, not just feature lists
- Test MCP server configurations before submitting
