# CLAUDE.md

This repository is a comprehensive reference for Claude Code tools, skills, MCP servers, and agent frameworks.

## Repository Purpose

A curated collection of 90+ tools organized into:
- **Skills** — Teach Claude HOW to do things better
- **MCP Servers** — Give Claude ACCESS to external tools and data
- **Agent Frameworks & GitHub Repos** — Orchestrate complex AI workflows

## Structure

- `README.md` — Master index with every tool listed
- `skills/` — Detailed guides per skill category
- `mcp-servers/` — MCP server setup and configuration
- `github-repos/` — Deep-dives into categorized repositories
- `guides/` — Quickstart and setup tutorials

## When Editing

- Keep tables consistent with the format: `| # | Name | Description | Link |`
- All GitHub links should use the format `[owner/repo](https://github.com/owner/repo)`
- Star counts are approximate and may be outdated — update when known
- New entries go at the end of their respective category table
- Maintain the numbering within each section
