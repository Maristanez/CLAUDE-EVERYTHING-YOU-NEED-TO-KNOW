# Knowledge & Learning Skills

Skills for knowledge management, note-taking, and learning workflows.

---

## 20. NotebookLM Integration

**Repo:** [PleasePrompto/notebooklm-skill](https://github.com/PleasePrompto/notebooklm-skill)

Bridges Claude and Google NotebookLM for enhanced knowledge management:
- Generate summaries from research materials
- Create mind maps from documents
- Build flashcards for study
- Cross-reference sources

## 21. Obsidian Skills

**Repo:** [kepano/obsidian-skills](https://github.com/kepano/obsidian-skills)
**Author:** Obsidian's CEO

Native Obsidian vault integration:
- Auto-tagging based on content
- Auto-linking between related notes

- Works with Obsidian's plugin ecosystem

## 22. Excel MCP Server

**Repo:** [haris-musa/excel-mcp-server](https://github.com/haris-musa/excel-mcp-server)

Manipulate Excel files without Microsoft Excel installed. Read, write, format, and analyze spreadsheets directly through Claude.
