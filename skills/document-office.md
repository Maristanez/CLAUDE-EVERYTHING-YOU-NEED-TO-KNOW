# Document & Office Skills

Official Anthropic skills for document processing and office automation.

## Overview

These skills let Claude Code create, edit, and process office documents directly — no Microsoft Office required.

---

## 1. PDF Processing

**Repo:** [anthropics/skills/pdf](https://github.com/anthropics/skills/tree/main/skills/pdf)

Read, extract tables, fill forms, merge/split PDFs. Handles complex layouts and multi-page documents.

**Use cases:**
- Extract structured data from invoices and receipts
- Fill out PDF forms programmatically
- Merge multiple PDFs into one
- Split large PDFs by page range

---

## 2. DOCX

**Repo:** [anthropics/skills/docx](https://github.com/anthropics/skills/tree/main/skills/docx)

Create and edit Word documents with tracked changes, comments, and formatting.

**Use cases:**
- Generate contracts and proposals from templates
- Add tracked changes for collaborative editing
- Convert markdown to formatted DOCX

---

## 3. PPTX

**Repo:** [anthropics/skills/pptx](https://github.com/anthropics/skills/tree/main/skills/pptx)

Create slide decks from natural language. Supports layouts, charts, and speaker notes.

**Use cases:**
- Generate investor pitch decks
- Create training presentations
- Build chart-heavy reports

---

## 4. XLSX

**Repo:** [anthropics/skills/xlsx](https://github.com/anthropics/skills/tree/main/skills/xlsx)

Work with Excel spreadsheets — formulas, analysis, and charts via plain English.

**Use cases:**
- Build financial models
- Create data analysis sheets with formulas
- Generate charts from raw data

---

## 5. Doc Co-Authoring

**Repo:** [anthropics/skills/doc-coauthoring](https://github.com/anthropics/skills/tree/main/skills/doc-coauthoring)

Real collaborative writing. Human writes, Claude responds, back and forth.

**Use cases:**
- Co-write blog posts and articles
- Collaborative editing with AI suggestions
- Iterative document refinement
